# Smart-Closet
## This project was inspired by the physical revolving closet from the 1995 movie Clueless

### Here are some more implementation details:
• Architected a full-stack IoT application with a 10-endpoint Flask REST API backend running on Raspberry Pi 5, handling client-server communication with Base64 image encoding and JSON serialization across GET/POST/DELETE requests.

• Designed backend support for a React Native (Expo) mobile frontend in JavaScript/Typescript with features including inventory management, clothing CRUD, and context-aware suggestions driven by real-time weather, calendar, and past wear history using open-source weather and calendar APIs.

• Integrated a diffusion model using Python for virtual try-on functionality and Gemini/Vertex AI for clothing classification, enabling AI-powered outfit recommendations from an edge device.
